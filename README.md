# PokerZone

Lokalna gra w Texas Hold’em z botami przy stole dla maksymalnie ośmiu graczy. Możesz wybrać stawki NL 5/10 lub NL 10/20 i przeglądać historię własnych rozdań.

## Uruchomienie

Otwórz `index.html` w przeglądarce. Gra używa HTML, CSS i JavaScript i działa bez instalacji.

## GitHub Pages

W ustawieniach repozytorium otwórz **Settings → Pages**. Wybierz **Deploy from a branch**, gałąź **main** i folder **/(root)**. Po publikacji gra będzie dostępna pod adresem [wojciechnosalgit.github.io/PokerZone/](https://wojciechnosalgit.github.io/PokerZone/).

## Historia rozdań

Historia zapisuje się automatycznie w przeglądarce dla danego adresu gry. W **Moich rozdaniach** możesz pobrać lub zaimportować plik JSON. W przeglądarkach z obsługą wyboru folderu możesz też włączyć automatyczny zapis pliku `poker-lab-historia.json` w wybranym folderze.

Jeśli masz historię z poprzedniej wersji, wybierz **Importuj JSON** i wskaż plik `Data/poker-lab-historia.json` z lokalnego katalogu projektu.
