# Graj online

[Otwórz PokerZone](https://pokerzone-online.onrender.com/)

1. Wybierz **Graj online → Utwórz stół**. Wpisz nick, ustaw stawkę oraz liczbę graczy i botów, a potem potwierdź utworzenie stołu.
2. Kliknij **Kopiuj link** i wyślij zaproszenie znajomym. Przycisk znajdziesz też w oknie **Zaproś** przy stole.
3. Znajomi otwierają zaproszenie, wpisują nick, klikają **Wybierz miejsce**, a potem **Usiądź** przy wolnym miejscu.

Jeśli wysyłasz znajomym adres PokerZone z góry tej strony, podaj im też kod stołu. Wpiszą go w **Graj online → Dołącz kodem**.
