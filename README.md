# PokerZone

Lokalna gra w Texas Hold’em z botami przy stole dla maksymalnie ośmiu graczy. Możesz wybrać stawki NL 5/10 lub NL 10/20 i przeglądać historię własnych rozdań.

## Uruchomienie

Gra wymaga Pythona 3.9 lub nowszego. W systemie Windows uruchom `start-poker-lab.cmd`, który otworzy grę w domyślnej przeglądarce.

Możesz też uruchomić `python server.py` w katalogu projektu i otworzyć [127.0.0.1:8765](http://127.0.0.1:8765) w przeglądarce.

Historia rozdań zapisuje się lokalnie w `Data/poker-lab-historia.json`.
